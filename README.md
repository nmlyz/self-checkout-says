self-checkout-says writes one line to a text file: the remark a smug self-checkout machine makes about a shopper's meal deal. The line was picked from 46 candidates by pairwise judging against the brief — the laugh sits in the reframe of a meal deal as a cry for help, and the twist lands on the last word, "barcode", which is the machine's own voice. The till does not raise its voice; it reads the basket, notes the meal deal, and lets the shopper hear exactly what it thinks of it.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 63 characters, a single line, and ends on its strongest beat. Before writing, the program runs the line through three gates — exact judged length, single line with no leading or trailing space, and every character printable — then reads the file back to confirm the bytes match.
